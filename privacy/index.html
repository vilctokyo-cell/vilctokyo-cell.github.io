プライバシーポリシー

制定日: 2026年10月8日

VILC（ビリック）（以下「当社」）は、当社のウェブサイト、各種サービス、およびマスコットキャラクター「ルヴィ」のライブ配信（以下「本サービス」）における個人情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

  • お問い合わせの際にご提供いただく氏名・連絡先・お問い合わせ内容
  • ウェブサイトの閲覧状況（Google アナリティクスによるアクセス情報）
  • YouTube ライブ配信のチャットに投稿されたコメントと、その投稿者の表示名

2. 利用目的

  • お問い合わせへの回答、お見積り・制作のご連絡のため
  • ウェブサイトの改善のため
  • ライブ配信中に、キャラクターがコメントへ返事をするため、および配信内容の振り返り（次回の配信で話題にするなど）のため

3. YouTube のデータの取り扱い

ライブ配信では、YouTube API サービスを利用して、当社チャンネルのライブ配信に投稿されたチャットのコメントを読み取ります。読み取ったコメントと表示名は、返事の文章を作るために AI サービス（Anthropic 社の Claude）へ送信し、配信の記録として当社の端末内に保存することがあります。これら以外の目的には使用せず、販売や広告目的での第三者提供は行いません。

本サービスは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 が、Google による情報の取り扱いには Google プライバシーポリシー が適用されます。当社によるアクセスは、Google アカウントのセキュリティ設定 からいつでも取り消すことができます。

4. アクセス解析ツール

当社ウェブサイトでは Google アナリティクスを利用しています。Google アナリティクスは Cookie を使用して、個人を特定しない形で閲覧状況を収集します。詳しくは Google のサイトでの説明 をご覧ください。

5. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく個人情報を第三者に提供することはありません。

6. お問い合わせ

本ポリシーおよび個人情報の取り扱いに関するお問い合わせは、下記までご連絡ください。

7. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点から適用されます。
